== Summary

This release contains a large number of mostly minor bug fixes for issues
identified by Claude and reported by Skye Soss.  There are a number of regular
bug fixes as well.  We have also added support for "mixed" records to the runtime
system.

== Details

// **** details: include those sections that are relevant

* Added constant folding for the rotation operators

=== Basis Library

A number of *Basis Library bugs were fixed (see the list below for details).

=== SML/NJ Library

A number of *SML/NJ Library* bugs were fixed (see the list below or the
`smlnj-lib/CHANGES` file for details).
